# 拾音浏览器助手

Chrome / Edge 辅助扩展，配合拾音网页使用。服务器被哔哩哔哩拒绝时，助手在你自己的浏览器打开普通视频页面，读取平台提供的完整独立 AAC 音轨，保存为 M4A 文件。网页继续管理扫描和下载状态。

## 安装与连接

1. 在拾音网页点击「下载浏览器助手」，解压 ZIP，得到 `shiyin-browser-helper` 文件夹。保留这个文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `shiyin-browser-helper` 文件夹。
4. 打开你使用的拾音网页，例如 `http://43.165.169.160:8080`。在浏览器工具栏的扩展菜单中点击「拾音浏览器助手」。
5. 点击「连接当前拾音网页」，同意给这个网页的连接权限，然后刷新拾音网页。网页显示「已连接」后即可扫描 B 站链接。

每个人在自己的 Chrome / Edge 安装并连接一次。换网站地址、协议或端口时，需要重新连接。插件一次只连接一个网站；连接新网站会断开旧网站。

## 扫描和下载

- B 站链接由助手依次打开到一个普通 B 站标签页。遇到登录、验证码或页面没有播放资料时，扫描暂停。请在该标签页自行完成平台要求并正常播放，再回拾音点击继续扫描。
- 支持公开的 BV 视频和分 P；`?p=2` 只扫描指定分 P。没有指定分 P 时按顺序读取，最多 100 个。
- 点击单个下载后，助手在临时来源页读取完整音轨，并显示读取进度，再保存到浏览器下载列表。批量下载分别保存音频文件，不生成 ZIP；浏览器可能要求允许多个文件下载。
- 混合选择 B 站和其他网站时，网页分别创建「浏览器保存文件」和「服务器 ZIP」任务。
- 网页显示准备、已传输字节、完成或失败。浏览器任务的「完成」来自 Chrome / Edge 下载结果；失败原因也会显示。
- 关闭拾音标签页后，已开始的浏览器下载仍由浏览器处理。重新打开页面需要重新扫描；平台音轨地址过期时也需要重新扫描。
- 助手会临时使用本机磁盘，保存结束后清理。请预留足够空间，并等待完成后再关闭助手打开的保存页面；每个音轨最多 3 GB。

只支持平台提供的完整、公开 AAC 音轨。付费、试看、DRM、直播、缺少完整播放资料或平台拒绝的内容不会保存。助手不自动解决登录或验证，也不保证所有视频都可处理。其他网站仍走服务器下载，原有地区或访问限制仍可能出现。

## 权限与数据

- 固定网站权限为哔哩哔哩，音轨读取仅接受已支持的官方 CDN 地址；另外只在你点击连接时请求当前拾音网站的权限。
- 使用浏览器下载、页面读取、状态存储和定时恢复权限。音频通过正常来源页读取，不修改浏览器的身份或认证信息。
- 浏览器会话、真实音轨地址和下载记录留在本机浏览器中。不会读取或导出 Cookie，也不会上传登录会话或音轨地址给拾音服务器。
- 网站只得到标题、时长、格式、临时文件标识和下载进度；当前网站和标签页不能读取其他标签页的插件任务。
- 在插件弹窗点击「断开连接」可撤销当前网站连接。已经开始的浏览器下载继续运行；也可从浏览器扩展管理页面禁用或卸载插件。

## 更新

从更新后的拾音网页重新下载 ZIP，解压并替换原文件夹里的文件，回到扩展管理页面点击该扩展的「重新加载」。回到拾音网页，在插件弹窗重新点击「连接当前拾音网页」，再刷新网页。部署服务器不需要安装浏览器。
